# Home Hierarchy and Tab Naming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Home's create doors and personalized suggestions above the fold, and rename the middle tabs so both are named for the format they produce.

**Architecture:** Two independent, string-and-order-only changes. Task 1 reorders the six `addArrangedSubview` calls in `HomeViewController.setupLayout()` and rewrites the two doc comments that describe the old stack. Task 2 changes three user-visible titles and the comments around them. No new types, no new files, no restyling — every view, closure and accessibility identifier is untouched.

**Tech Stack:** Swift 6, UIKit, XCTest/XCUITest, XcodeGen, Xcode 26.5 / iOS 26.5 SDK, iPhone 17 simulator.

**Spec:** `docs/superpowers/specs/2026-09-04-home-hierarchy-and-tab-naming-design.md`

## Environment setup (run once per session, before any task)

The macOS CLI defaults to CommandLineTools, so `xcodebuild` fails until it is pointed at
Xcode. The `.xcodeproj` is generated by XcodeGen and gitignored, so regenerate it first.

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
export PATH="$DEVELOPER_DIR/usr/bin:$PATH"
cd "/Users/irony/Claude/Projects/ClaudeCollage"
xcodegen generate
```

Pre-boot one simulator and address it **by id** for every run below. Letting `xcodebuild`
pick and boot a device itself is what wedges the simulator with
`Busy ("Application failed preflight checks")`:

```bash
xcrun simctl shutdown all
DEV=$(xcrun simctl list devices available | grep -E 'iPhone 17 \(' | head -1 | grep -oE '[0-9A-F-]{36}')
xcrun simctl boot "$DEV"; xcrun simctl bootstatus "$DEV" -b
echo "DEV=$DEV"
```

`bootstatus` ending `Status=4294967295, isTerminal=YES ... Finished` is success, not an error.

**Never run two simulator jobs at once.** Do not `simctl erase all` — it resets Photos
authorization and breaks `ExportSaveUITests`.
